# 形象人设填写模板

复制下面 YAML 块，按角色填写后交给开发合并进 `js/personas-data.js`。`vector` 六维取值建议在 **[-1, 1]**，与题目计分尺度一致。

---

## 填写说明

1. **头像**：可选，放在 [`assets/`](../assets/) 下；留空则由页面按名字自动生成占位图。支持 `.png` / `.jpg` / `.svg`。
2. `id` 建议 **persona_ + 英文短名**，例如 `persona_lin`。
3. `archetypeHints` 里只把**符合**的标签设为 `true`，其余保持 `false`：
   - `mentorBias`：更像带路、拆步骤的那位 → 容易落到师徒 / 带路人档
   - `partyEnergy`：更爱攒局、热场 → 容易落到酒肉搭子档
   - `rivalBias` / `rebel`：冲突维突出、爱顶牛 → 容易落到对手 / 冤家档
   - `balanced`：六维较居中 → 关系标签更「普通」

---

## 六维 vector 对照（填数参考）

| 维 id | 接近 +1 更像 | 接近 -1 更像 |
|--------|---------------------|----------------------|
| social | 更爱社交、主动约人 | 更偏独处、慢热 |
| structure | 爱计划、deadline 不慌 | 更随性、临时改计划 |
| conflict_direct | 分歧当场说清 | 先缓冲、改天再聊 |
| emotion_expr | 情绪外显、爱倾诉 | 更内敛、自己消化 |
| risk | 更敢冒险 | 更求稳 |
| authority | 更听经验/层级 | 更自主、不爱被指导 |
